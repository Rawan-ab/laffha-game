# Laffha Multiplayer Prototype

هذا المجلد للتجربة فقط وموجود على فرع `multi-prototype` حتى لا يؤثر على اللعبة الأساسية الموجودة على `main`.

## الصفحات
- `index.html` — مدخل التجربة.
- `host.html` — شاشة العرض على اللابتوب/التلفزيون.
- `join.html` — واجهة جوال الفريق.
- `styles.css` — هوية وتجهيزات واجهات اللعب الجماعي.

## الحالة الحالية
- واجهات فقط بدون ربط حقيقي بين الأجهزة.
- كود الغرفة والـQR تجريبيان.
- جوال الفريق يحتوي حالات جاهزة للتجربة: دخول، انتظار، سؤال اختيارات، تأكيد وإرسال، وتوب 10.
- اللعبة الأصلية غير متأثرة.

## المرحلة التالية بعد اعتماد التصميم
1. إضافة Room backend مستقل.
2. ربط Host وJoin عبر Realtime.
3. تحويل QR إلى رابط غرفة حقيقي.
4. اختبار لابتوب + جوالين.
5. إضافة سؤال MCQ حقيقي ثم Top 10.
6. بعد نجاح الاختبار فقط: نقل النظام إلى السيرفر/المشروع الأساسي.
