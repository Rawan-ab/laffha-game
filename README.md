# لفّها — Arabic Group Quiz Game

نسخة MVP قابلة للعب مباشرة من المتصفح، مصممة بالعربية وRTL وبواجهة Light Theme.

## الموجود الآن
- 2–6 فرق مع أسماء مخصصة
- 5 / 7 / 10 جولات
- اختيار الفئات
- Spin Wheel عشوائية
- مستويات 200 / 400 / 600
- مؤقت 60 ثانية محسوب بالوقت الفعلي
- Scoreboard دائم
- منع تكرار الأسئلة داخل الجلسة
- تلميح، 50/50، +15 ثانية، تغيير سؤال
- أسئلة عربية متنوعة: مباشر، اختيار متعدد، Emoji
- شاشة نتيجة وفائز
- Responsive للجوال والكمبيوتر

## التشغيل محليًا
افتح `index.html` مباشرة، أو شغّل خادمًا بسيطًا:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## بنية بنك الأسئلة
الأسئلة موجودة في `questions.js` بشكل مستقل عن منطق اللعبة، لذلك يمكن توسيع البنك بدون تعديل واجهة اللعبة.
